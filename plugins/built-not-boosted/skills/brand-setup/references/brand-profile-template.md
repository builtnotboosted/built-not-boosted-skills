# Brand profile template

Copy everything below the line into `marketing/brand/brand-profile.md` and fill it in. The comments explain what each section is for and which skills read it; delete them once the section is filled. Keep the twelve `##` headings exactly as written and in this order, because the other skills look them up by name.

Anything you don't know yet: write `TODO:` and what's missing. Never fill a gap with a guess.
