# Platform posting notes

Last checked: Nov 2026. Platforms change these often, so verify before relying on any of it, especially link behaviour and limits. When it matters (a launch, a paid push, a post built around a link), check the platform's own help pages or the scheduler's docs live.

Brand-profile `## Platforms` is where the person's own decisions live (which platforms, links allowed or not, manual or scheduler). These notes are the background that informs those decisions.

## Links

| Platform | Link behaviour (Nov 2026) | Practical default |
|---|---|---|
| Facebook Page | Meta began rationing organic link posts on Pages in 2026; link posts can be capped or down-ranked. | Link-free by default. If you use links, set a small monthly budget in brand-profile and spend it on your strongest pieces, link in the first comment. |
| Facebook personal profile | No third-party tool can auto-publish to a personal profile. | Manual post or reminder. |
| Instagram | Caption links are not clickable; link features in posts are increasingly paid. | Never put a URL in the caption. Point to the profile ("link on my profile") only when it genuinely helps. |
| LinkedIn | Links in the post body can reduce reach but are normal for article, event or long-form releases. | Allow only for a stated reason (article, event booking, long-form release). |
| TikTok | Caption links are not clickable for most accounts. | Link-free, point to the profile. |
| YouTube | Description links work; schedulers often cannot post or pin comments. | Links in the description; pinned comment by hand. |
| Google Business Profile | Google applies its business links policy: no shorteners, no social or link-in-bio aggregators, crawlable dedicated pages only. Body links are discouraged; use the button. | One call-to-action button per post (Learn more, Book, Call and so on) pointing at a real page on your own site or a full booking or form URL. |

Comment-keyword asks ("comment GUIDE below") are treated as engagement bait and demoted on most platforms. A genuine question works better.

## Post types and flags

- **YouTube Shorts:** vertical 9:16, under 3 minutes. Needs a title; tags help. Mark it as a Short in the scheduler or it may land as a normal upload.
- **Instagram Reels:** vertical 9:16. Mark it as a Reel; an unflagged video can post as a feed video with less reach.
- **TikTok:** vertical 9:16 video. Photo-mode carousels exist, but engagement on them can be very low, so test before relying on them.
- **Facebook:** video can go as a Reel or a feed video; check which your tool sends.
- **LinkedIn:** carousels are usually PDF document posts. Native video and single images work normally.
- **Carousels on Instagram:** up to 20 items in 2026 (check), images and video can be mixed on the platform, but not every scheduler supports mixing.
- **Google Business Profile:** photo posts with one button. Some tools need a one-minute gap between posts on the same listing.

## Media shapes (safe defaults)

| Use | Shape | Pixels |
|---|---|---|
| Feed image (Instagram, Facebook, LinkedIn) | 4:5 portrait | 1080 x 1350 |
| Square fallback | 1:1 | 1080 x 1080 |
| Shorts, Reels, TikTok, Stories | 9:16 | 1080 x 1920 |
| Long-form video, YouTube thumbnails | 16:9 | 1920 x 1080 (thumbnail 1280 x 720) |
| Business listing photo | 4:3 or 1:1 | 1200 x 900 or 1080 x 1080 |

Keep text out of the outer 10-15% on vertical video so platform buttons do not cover it.

## Alt text

Instagram, Facebook, LinkedIn and X support alt text on images; most schedulers pass it through if you set it per image. Write what is in the picture in a sentence or two, not the caption again and not a list of keywords.

## Accounts that need a human

- Personal Facebook profiles (manual or reminder).
- YouTube pinned comments, community posts on some tools.
- Anything behind a login challenge or two-factor prompt.

List these as hand jobs in the manifest with the exact text ready to paste.
