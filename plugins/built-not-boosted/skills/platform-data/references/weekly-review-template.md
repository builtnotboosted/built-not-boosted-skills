# Weekly review template

Save as `data/reviews/<yyyy-mm-dd>-weekly-review.md`, dated the day the review is written. Aim for something the person can read in five minutes. Tables are fine; long prose is not. Put a five-line summary in chat when it is done.

Leave a section in with "nothing this week" rather than deleting it, so it is clear it was checked.

---

```markdown
# Weekly review: week to YYYY-MM-DD

**Window:** YYYY-MM-DD to YYYY-MM-DD (and the longer comparison window, e.g. 28 days)
**Sources:** <snapshot files in data/, e.g. data/2026-11-08-publer-28d.md, data/2026-11-08-gsc-28d.csv>
**Coverage:** <platforms included; anything missing or partial, and why>
**Reach floor used:** 50

## In five lines
1. The headline: what happened this week, in one sentence.
2. What worked, with its number.
3. What did not, with its number.
4. What changed in the learnings.
5. The one thing to do differently next week.

## The real goal
| Measure (from ## Offer & goal) | This week | Last week | Notes |
|---|---|---|---|
| Enquiries / bookings / sales | | | source of the count |
| Link clicks | | | |
| Profile visits / follows | | | |
If there is no attribution yet, say so here.

## Reach board (top 5-10 by reach, all platforms)
| Post (date, short title) | Platform | Format | Pillar | Hook type | Reach | Eng. rate | Saves | Shares | Comments | Age (days) |
|---|---|---|---|---|---|---|---|---|---|---|
Outliers: name any single post carrying a big share of the window, separately.

## Engagement board (above the reach floor only)
| Post | Platform | Format | Reach | Eng. rate | What drove it |
|---|---|---|---|---|---|

## Per platform
| Platform | Posts | Median reach | Median eng. rate | Followers (net) | Read |
|---|---|---|---|---|---|
One line each on what the platform is doing for the business right now.

## Formats
Which formats did their job this week (video for reach, stills and carousels for saves and comments, questions for conversation). Note anything that contradicts the learnings.

## Timing
Best-time read from the platform's own follower-activity data and from the scheduler grid, with the caveat if one post is driving a cell. Status of any live timing test.

## Search
Search Console and platform search terms: new queries, queries on page one with nothing built for them, clicks on question queries.

## Learnings updated
| Entry | Change | Evidence | New confidence |
|---|---|---|---|
| e.g. "Question-led hooks out-engage announcements on TikTok" | strengthened | 3rd confirming window, 4 posts above floor | pattern |
Promotions to rule proposed for the person's sign-off:

## Recommendations for next week
**Format:** ...
**Timing:** ...
**Topics:** seams to keep mining; gaps from search and comments (hand to the research skill).
**Weekly pick:** for each platform, the 3-5 strongest candidate pieces from what is planned, ranked, with a one-line reason each.
Label each recommendation: evidence | pattern | hypothesis.

## Tests
| Test | Arms | Started | Ends | Posts logged | Read so far |
|---|---|---|---|---|---|

## Caveats
Coverage gaps, posts still accumulating, small samples, metric definitions that differ across platforms.
```
