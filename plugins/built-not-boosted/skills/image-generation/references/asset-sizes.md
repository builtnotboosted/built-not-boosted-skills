# Asset sizes per platform

**Last checked: Nov 2026, verify before relying on it.** Platforms change sizes, crops and grid shapes without much notice. When a size matters (a paid campaign, a new banner, a format you have not posted before), check the platform's own help page or upload a test privately and look at it on a phone.

Finish every file to exactly these pixels. "Grid tile" is how the piece appears on the profile grid, which is where new visitors judge the account.

## Feed images and carousels

| Platform | Use | Size | Notes |
|---|---|---|---|
| Instagram | feed portrait (best default) | 1080x1350 (4:5) | Grid tile shows a 3:4 centre crop; keep text in the central square to be safe |
| Instagram | feed square | 1080x1080 (1:1) | |
| Instagram | carousel slide | 1080x1350 (4:5) | Up to 20 slides; all slides share the first slide's ratio |
| Facebook | feed portrait | 1080x1350 (4:5) | Square 1080x1080 also fine |
| Facebook | link share image | 1200x630 (1.91:1) | Usually pulled from the page's Open Graph image |
| LinkedIn | feed image | 1080x1350 (4:5) or 1200x1200 (1:1) | Landscape 1200x627 also supported |
| LinkedIn | document (PDF) carousel | 1080x1350 per page | Export slides as one PDF |
| Threads | feed image | 1080x1350 (4:5) | |
| Bluesky | feed image | 1000x1000 (1:1) or 1080x1350 (4:5) | Supports alt text |
| X | in-stream image | 1600x900 (16:9) or 1080x1080 (1:1) | Tall images are cropped in the timeline preview |
| Pinterest | standard pin | 1000x1500 (2:3) | |
| Google Business Profile | post / update image | 1200x900 (4:3) | Never portrait; it crops hard. Keep phone numbers and web addresses out of the image (posts with them baked in have been rejected); put them in the post text |
| Google Business Profile | cover photo | 1024x576 (16:9) minimum | |

## Video covers and thumbnails

| Platform | Use | Size | Notes |
|---|---|---|---|
| Instagram Reels | cover | 1080x1920 (9:16) | Grid shows a 3:4 centre crop (about rows 240 to 1680); keep text in the central square (rows 420 to 1500) |
| TikTok | cover | 1080x1920 (9:16) | Grid tile is roughly 3:4; the play count sits bottom-left and pinned labels top-left |
| YouTube Shorts | cover | 1080x1920 (9:16) | Shorts covers are chosen in the mobile app; the shelf crops tighter than the full frame |
| YouTube | long-form thumbnail | 1280x720 (16:9) | Under 2 MB, JPG or PNG (JPG is safer for the size cap). Duration badge sits bottom-right |
| LinkedIn | article / newsletter cover | 1920x1080 (16:9) | 1280x720 also fine |
| Facebook Reels | cover | 1080x1920 (9:16) | |

## Alt text support

Instagram (advanced settings when posting), Facebook, LinkedIn, X, Bluesky and Threads all accept alt text on images, and most schedulers can pass it through. Keep each line under about 125 characters so it fits everywhere and reads comfortably on a screen reader.
